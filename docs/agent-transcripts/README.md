# Agent transcripts
This project was built with Claude (Claude Code–style agent) in a single session. `01-build-log.md` is a curated, chronological log of the
decisions, failures and fixes (no secrets). **Before submitting, also export your own raw session transcript from your coding agent into this folder**
(e.g. `02-raw-session.md`) — the assignment asks for the actual logs, and a curated summary alone may not be enough.
